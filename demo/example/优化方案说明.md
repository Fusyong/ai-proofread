# HTML文件优化方案

## 优化结果

### 基础优化（optimize_html.py）
- **减少**: 23.3% (18.2 KB)
- **输出**: `a1.alignment.optimized.html`

### 高级优化（optimize_html_advanced.py）
- **减少**: 26.6% (20.8 KB)
- **输出**: `a1.alignment.minified.html`

## 优化策略

### 1. 压缩HTML空白
- 移除标签之间的多余空白
- 压缩script和style内的空白
- 移除HTML注释

### 2. 优化HTML属性
- 移除默认值属性（如 `data-diff-mode="false"`）
- 简化class属性（去重）
- 移除不必要的title属性

### 3. 移除重复数据
- 对于完全匹配的行（similarity=1.0000），移除data-text属性中与显示内容相同的文本
- 这样可以显著减少文件大小，因为完全匹配的行占大多数

### 4. 表格结构优化
- 简化重复的HTML标签结构
- 优化单元格内容

## 进一步优化建议

### 方案A：提取外部资源（推荐用于开发环境）
将CSS和JavaScript提取到外部文件：
- 优点：可以缓存，减少重复下载
- 缺点：需要管理多个文件
- 使用方法：修改 `optimize_html.py` 中的 `extract_external = True`

### 方案B：使用数据驱动方式（需要修改生成代码）
将表格数据存储为JSON，通过JavaScript动态生成：
```javascript
// 数据格式
const alignmentData = [
  {idx: 1, type: 'match', similarity: 1.0, textA: '...', textB: '...'},
  // ...
];
```
- 优点：可以大幅减小文件（减少50%以上）
- 缺点：需要修改生成HTML的代码

### 方案C：使用压缩算法
生成gzip压缩版本（.html.gz）：
- 优点：可以再减少60-70%
- 缺点：需要服务器支持或解压工具

### 方案D：优化生成代码（最佳方案）
在生成HTML时就应用优化：
1. 对于完全匹配的行，不存储data-text（或只存储空字符串）
2. 使用更紧凑的HTML结构
3. 避免重复存储相同内容

## 使用建议

1. **单文件分发**：使用 `a1.alignment.minified.html`（减少26.6%）
2. **进一步优化**：考虑方案B（数据驱动），可以再减少30-40%
3. **长期方案**：修改生成HTML的代码，在生成时就应用优化

## 注意事项

- 优化后的文件功能保持不变
- 建议保留原始文件作为备份
- 如果使用外部资源方案，需要确保CSS和JS文件在同一目录
