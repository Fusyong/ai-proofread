# 中文句子切分算法设计说明

## 概述

`split_chinese_sentences()` 函数实现了智能的中文句子切分功能，能够处理各种复杂的文本格式和边界情况。

## 句子结尾标记

### 1. 基本句末标点

- **中文标点**：`。！？…`（省略号）
- **英文标点**：`.!?`（在中文语境中）
- **后续标记**：句末标点后可能跟引号、括号等，如：`。"`、`。）`、`。]` 等

### 2. 段落标记

- **空行**：遇到空行时，即使当前句子没有句末标点，也会切分
- **换行符**：在某些情况下，换行符也可以作为句子边界

## 特殊情况的处理

### 1. 列表项和标题

**问题**：Markdown 列表项和标题末尾常常没有标点符号。

**解决方案**：
- 标题：标题本身作为一句，即使没有标点
- 列表项：
  - 如果列表项内容以句末标点结尾，立即切分
  - 如果列表项没有句末标点，遇到空行或新列表项/标题时切分

### 2. 引号内的句号

**问题**：引号内的句号通常不是句子结尾，如 `"他说："你好。""`

**解决方案**：
- 跟踪引号状态（支持多种引号类型：`"`、`"`、`'`、`'`、`「`、`」`、`『`、`』`）
- 只有在引号外的句末标点才被视为句子结尾

### 3. 小数点识别

**问题**：数字后的句号可能是小数点，如 `3.14`

**解决方案**：
- 检查句号前后是否都是数字
- 如果是数字，则不是句子结尾

### 4. 英文句号

**问题**：在中文文本中，英文句号也可能是句子结尾，但也可能是缩写或小数点。

**解决方案**：
- 如果前后都是数字，视为小数点
- 如果后面跟小写字母或数字，可能是缩写，不切分
- 如果前面是中文，可能是句子结尾

### 5. 省略号

**问题**：省略号可能是 `…`（单个字符）或 `...`（三个点）

**解决方案**：
- 支持中文省略号 `…`
- 支持英文省略号 `...`（作为句子结尾）

## 函数说明

### `split_chinese_sentences(text, preserve_formatting=True)`

主函数，支持两种模式：

- **`preserve_formatting=True`**（默认）：
  - 保留原始格式（换行、空格等）
  - 考虑 Markdown 格式（标题、列表项等）
  - 适合处理 Markdown 文档

- **`preserve_formatting=False`**：
  - 纯文本模式，不保留格式
  - 适合处理纯文本内容

### `split_chinese_sentences_simple(text)`

简化版函数，仅按句末标点切分，不考虑格式。适用于：
- 纯文本内容
- 不需要保留格式的场景
- 快速切分

## 使用示例

```python
from src.splitter import split_chinese_sentences, split_chinese_sentences_simple

# 基本用法
text = "这是第一句话。这是第二句话！"
sentences = split_chinese_sentences_simple(text)

# Markdown 格式文本
markdown_text = """# 标题

这是段落。这是另一句话！

- 列表项
"""
sentences = split_chinese_sentences(markdown_text, preserve_formatting=True)
```

## 算法复杂度

- **时间复杂度**：O(n)，其中 n 是文本长度
- **空间复杂度**：O(n)，用于存储结果

## 已知限制

1. **嵌套引号**：目前不支持复杂的嵌套引号场景（如 `"他说：'你好。'"`）
2. **括号内句号**：括号内的句号目前会被视为句子结尾（可能需要根据上下文判断）
3. **英文缩写**：英文缩写（如 `Dr.`、`Mr.`）可能被误判为句子结尾

## 未来改进方向

1. 支持更复杂的引号嵌套
2. 改进括号内句号的处理逻辑
3. 支持英文缩写识别
4. 支持更多标点符号组合
5. 提供可配置的切分规则
