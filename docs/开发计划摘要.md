# 新对齐算法开发计划摘要

## 核心改进点

1. **双链结构**：维护连续的对齐结果，确保不遗漏、不重复
2. **分阶段对齐**：先全等匹配，再相似度匹配
3. **规范化处理**：比较时规范化（删除空格、转换引号），结果用原始文本
4. **分组与交叉处理**：识别匹配组，处理交叉情况
5. **多阶段调试**：每个阶段输出HTML报告

## 开发阶段（总计约15-20天）

1. **阶段1**：基础框架（1-2天）
2. **阶段2**：全等匹配（2-3天）
3. **阶段3**：相似度匹配基础（3-4天）
4. **阶段4**：合并匹配（3-4天）
5. **阶段5**：分组与交叉（2-3天）
6. **阶段6**：整合优化（2-3天）
7. **阶段7**：测试文档（2-3天）

## 关键技术

- 双链维护算法
- 分组识别算法
- 交叉检测算法
- 合并匹配算法

## 可沿用部分

- 句子切分模块（splitter.py）
- 相似度计算（需扩展规范化）
- HTML报告生成（需支持多阶段）
- 统计功能

## 需要重写

- 对齐核心算法
- 多对一/一对多处理逻辑
